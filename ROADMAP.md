# План развития Moth

Первая цель — стабильный Android-клиент. Сроки пока не зафиксированы.

## Классический клиент

- [x] Импорт подписки, ручной выбор серверов, подключение и отключение.
- [x] Шифрование конфигураций и ручное обновление.
- [x] Первое тестирование: Samsung S24 Ultra, Android 16.
- [ ] Другие устройства и форматы подписок.
- [ ] Проверки DNS/IPv6, сна устройства, отказов и отзыва разрешения.
- [ ] Обновление ядра, современные транспорты, включая XHTTP.
- [ ] Постоянная подпись и APK по архитектурам.

## Автоматика

- [ ] Проверка настоящего соединения через туннель.
- [ ] Выбор доступного профиля с учётом стабильности.
- [ ] Восстановление при смене сети без постоянного перебора серверов.
- [ ] Фоновые обновления с сохранением последней рабочей конфигурации.
- [ ] Диагностика без секретов подписки.

## Дальше

- [ ] Windows/Linux, затем iOS с отдельной VPN-интеграцией.
- [ ] Другие ОС при наличии ресурсов.
- [ ] Прозрачные партнёрские предложения и независимый каталог провайдеров.

Свои серверы, платежи и аккаунты не входят в первую версию.
