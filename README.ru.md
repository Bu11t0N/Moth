# Moth — Мотылёк

Открытый VPN-клиент для Android на Kotlin и Jetpack Compose с ядрами sing-box и Xray. Добавьте подписку, выберите сервер и подключитесь.

[Скачать](https://github.com/Bu11t0N/Moth/releases/latest) · [English](README.md) · [Сообщить об ошибке](https://github.com/Bu11t0N/Moth/issues)

## Возможности

- Несколько подписок со своими названиями, трафиком, сроком, напоминаниями и автообновлением, а также свои серверы («Мои серверы»).
- Добавление подписки или сервера по ссылке (ссылки импорта Moth, v2rayNG, Happ, Hiddify и sing-box, ссылки серверов); Moth всегда спрашивает подтверждение.
- Отдельный выбор сервера для Wi-Fi и мобильных данных, избранное и «Автовыбор лучшего сервера».
- Проверки HTTPS через сервер, TCP-порта, состояния туннеля.
- Kill switch, переподключение при смене сети, запуск при включении телефона и Always-on VPN.
- Раздельное туннелирование по приложениям, правила маршрутизации (домены, части имени, IP: через VPN, напрямую или блокировать) и «Российские сайты и IP напрямую».
- Настройки DNS с защитой от утечек DNS; обход DPI (фрагментация TLS, UDP-шум) и мультиплексирование, по умолчанию выключены.
- Статистика трафика, резервная копия (по желанию с паролем), необязательные обновления из приложения.
- Плитка в быстрых настройках и виджет на главном экране, оба показывают «Трафик заблокирован» / «Переподключение…».
- Русский и английский; при русской локали название приложения — «Мотылёк». Монохромный дизайн: светлая, тёмная, чёрная (AMOLED) и системная темы.

Нужна подписка совместимого провайдера или свой сервер. Собственных VPN-серверов в приложении нет.

## Установка

Требуется **Android 8.0 или новее**.

1. Скачайте APK из [релизов](https://github.com/Bu11t0N/Moth/releases/latest). Для большинства современных телефонов, нужен `arm64-v8a`; для старых ARM — `armeabi-v7a`; для соответствующих устройств и эмуляторов — `x86_64` или `x86`.
2. Установите APK и добавьте HTTPS-ссылку подписки от провайдера.
3. На вкладке «Серверы» выберите сервер отдельно для Wi-Fi и мобильных данных.
4. На «Главной» нажмите кнопку подключения и выдайте системное разрешение VPN.

На Android 13+ кнопку в шторку можно добавить через **Настройки → Интерфейс → Добавить кнопку VPN в шторку**. Также можно открыть редактирование быстрых настроек Android и перенести туда плитку «Мотылёк» / Moth. При первом подключении плитка откроет приложение для выдачи разрешения VPN.

Язык выбирается в **Настройки → Интерфейс**. По умолчанию используется язык системы. На Android 13+ выбор доступен и в системных настройках языка приложения.

История версий: [CHANGELOG.ru.md](CHANGELOG.ru.md).

Журнал для разработчиков (Настройки → Для разработчиков → Журнал): уровни, отправка и очистка; ссылки подписки, ключи и адреса серверов не записываются.

## Подписки и проверки

Поддерживаются текстовые и Base64-списки URI, Clash YAML/JSON (встроенный `proxies` или `proxy-providers` со ссылками на другие списки), конфигурации sing-box, а также Xray-core JSON (массив конфигураций, одна конфигурация или список outbounds): VLESS и Hysteria 2 становятся серверами, конфигурация с балансировщиком — одним сервером-балансировщиком. Правила маршрутизации, DNS и inbounds из таких конфигураций игнорируются. Протоколы: VLESS, VMess с `alterId=0`, Trojan, Shadowsocks без плагинов (и с ShadowTLS), Hysteria v1, Hysteria2, TUIC v5, AnyTLS, SOCKS5 и HTTP(S) с логином и паролем, WireGuard и SSH. AmneziaWG пока не поддерживается. Таблица транспортов и ограничения приведены в [основном README](README.md#supported-subscriptions).

HTTPS-проверка передаёт трафик через сервер; задержка включает установление HTTPS-соединения и не является ICMP ping. TCP проверяет только доступность порта, не работу VPN, и не подходит для UDP-протоколов Hysteria/TUIC.

Для проверки мобильных данных отключите Wi-Fi. Результаты разделены по типу сети, помечаются при её смене и сбрасываются после завершения процесса. Фильтр скрывает только неудачные HTTPS-проверки за последние 15 минут в текущей сети. Непроверенные, отменённые и TCP-проверки остаются видимыми.

## Приватность

Рекламы, аналитики и скрытой телеметрии нет. Подписки и настройки хранятся в AES-GCM файлах с ключом Android Keystore; резервное копирование и логи ядра отключены. Ссылки отправляются сервису подписки, а не разработчикам Moth.

HWID — случайный UUID установки, без IMEI и серийного номера. Модель и версия Android передаются по умолчанию; их можно отключить или заменить своими значениями. Заголовки устройства не пересылаются другому сайту при перенаправлении. Ссылки и HWID скрыты в полях ввода; скриншоты и трансляция разрешены.

Загрузка подписки и bootstrap DNS могут идти напрямую. DNS трафика внутри туннеля проходит через выбранный сервер. Bootstrap DNS можно изменить в настройках подключения.

С включённым kill switch трафик блокируется, пока Moth переподключается. Always-on VPN и блокировка соединений без VPN в Android тоже поддерживаются. Приложения, исключённые раздельным туннелированием, не могут отправлять трафик через VPN. Сертификаты, установленные пользователем, принимаются для серверов и загрузки подписок. Полная проверка DNS/IPv6-утечек ещё не выполнена. Доступность зависит от сервера, конфигурации и сети. Не публикуйте ссылки подписок, пароли и приватные ключи в отчётах об ошибках.

## Moth 0.4.5 и новее

Идентификатор приложения — `org.mothvpn.android`. Версия 0.4.5 устанавливается отдельно от старого пакета: сохраните URL подписки перед удалением старого приложения. Следующие версии обновляют новый пакет обычным способом.

Обновления необязательны: Настройки → Обновления. Автоматического скачивания и установки нет. Moth выбирает APK для архитектуры устройства, проверяет контрольную сумму и сертификат подписи, затем открывает системный установщик. Android может сначала запросить разрешение на установку из Moth.

### Подпись релизов

Релизные сборки требуют отдельное хранилище ключа Moth. Задайте путь в `MOTH_KEYSTORE_FILE` и пароль безопасным способом в `MOTH_KEYSTORE_PASSWORD`; псевдоним ключа — `moth`. Не создавайте новый ключ для уже установленного приложения. Сохраните офлайн-копию хранилища и пароля. GitHub Actions может использовать зашифрованные секреты репозитория `MOTH_KEYSTORE_BASE64` и `MOTH_KEYSTORE_PASSWORD`. Ключ и пароль не хранятся в репозитории и файлах релиза.

Без секретов подписи CI создаёт явно неподписанные проверочные APK; они не являются устанавливаемыми обновлениями.
